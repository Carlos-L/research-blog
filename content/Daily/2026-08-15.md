### 2. TIA需求文档整理

因为可能会找其他熟悉电路设计的组的同学帮忙，所以整理了一份需求文档

|       参数       |                                              典型值                                               |
| :------------: | :--------------------------------------------------------------------------------------------: |
|  本振光功率_PLO_​   |                                         +10 dBm（10 mW）                                         |
|  信号光功率_Psig_​  |                                        -70 dBm（100 pW）                                         |
|  光电二极管响应度_R_   |                                       0.9 A/W @ 1550 nm                                        |
|   差分交流光电流幅度    | ![](file:///C:/Users/admin/AppData/Local/Temp/msohtmlclip1/01/clip_image002.png) ​≈ **1.8 µA** |
| 每臂直流光电流（LO 贡献） | ![](file:///C:/Users/admin/AppData/Local/Temp/msohtmlclip1/01/clip_image004.png) ≈ **4.5 mA**  |
|     所需跨阻增益     |                               ≥ 50 kΩ（输出 ~100 mV）（如果难以达到可以适当放低）                                |
|      信号带宽      |                                       3GHz（如果难以达到可以适当放低）                                       |
|      输出接口      |                                           差分电压，交流耦合                                            |

目的：用于高速低噪声平衡零差探测器，signal大约-70dbm LO大约10dbm，只关注交流部分，噪声尽可能低

关键参数：  
跨阻增益50 kΩ（如果难以达到可以适当放低）
信号带宽3 GHz（如果难以达到可以适当放低）
PD结电容 1pF
PD反偏电压3V（最好设置成可调的，在1-5V内可调，设置成5V也行）
低频截止频率 50KHz – 100KHz
噪声尽可能低
频率响应尽可能增益平坦
相位裕度大于45度，避免震荡

备注：可以采取二级放大甚至多级放大设计；如果只是采取一级放大，带宽和增益估计很难兼得。可以譬如第一级用较小的反馈电阻（如 2 kΩ）保证带宽，第二级用电压放大器（如 20 倍）提升增益。
